# Chinese Jenkins Master-Tooling Assembly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Chinese dev Jenkins job build immutable `zdoc_cn/dev` generated content with immutable `zdoc_cn/master` tooling, while removing only the sidebar tooling on master that is proven stale.

**Architecture:** Preserve the existing polling checkout of the requested content branch, record its commit, then perform a non-polling checkout of master and restore checkpoint-owned generated paths from the recorded content SHA. Keep the root Chinese Docusaurus production model for this repair, including its legacy BYOC version tree, and simplify the master sidebar module so it directly exports the generated frontmatter sidebar name.

**Tech Stack:** Jenkins Declarative Pipeline and GitSCM, Git, Bash, Node.js built-in test runner, Docusaurus 3.10, Yarn 1, Docker, Harbor, Argo CD.

### Task 3: Implement the Jenkins two-SHA checkout and assembly

**Files:**

- [ ] **Step 1: Replace the Checkout stage with an immutable content/tooling assembly stage**

Replace the existing `stage('Checkout')` block with:

```groovy
stage('Checkout and Assemble') {
    steps {
        script {
            def contentCheckout = checkout([
                $class: 'GitSCM',
                branches: [[name: "*/${params.BRANCH}"]],
                extensions: [[$class: 'PruneStaleBranch'], [$class: 'CleanBeforeCheckout']],
                userRemoteConfigs: [[
                    url: 'https://github.com/zilliztech/zdoc_cn.git',
                    credentialsId: env.GITHUB_CREDENTIAL_ID
                ]]
            ])
            env.CONTENT_SHA = contentCheckout.GIT_COMMIT
            if (!(env.CONTENT_SHA ==~ /[0-9a-f]{40}/)) {
                error "Invalid content commit SHA: ${env.CONTENT_SHA}"
            }

            def toolingCheckout = checkout(
                changelog: false,
                poll: false,
                scm: [
                    $class: 'GitSCM',
                    branches: [[name: '*/master']],
                    extensions: [[$class: 'PruneStaleBranch'], [$class: 'CleanBeforeCheckout']],
                    userRemoteConfigs: [[
                        url: 'https://github.com/zilliztech/zdoc_cn.git',
                        credentialsId: env.GITHUB_CREDENTIAL_ID
                    ]]
                ]
            )
            env.TOOLING_SHA = toolingCheckout.GIT_COMMIT
            if (!(env.TOOLING_SHA ==~ /[0-9a-f]{40}/)) {
                error "Invalid tooling commit SHA: ${env.TOOLING_SHA}"
            }

            env.CONTENT_SHORT = env.CONTENT_SHA.take(9)
            env.TOOLING_SHORT = env.TOOLING_SHA.take(9)
            echo "Content SHA: ${env.CONTENT_SHA}"
            echo "Tooling SHA: ${env.TOOLING_SHA}"

            sh 'git cat-file -e "${CONTENT_SHA}^{commit}"'
            sh 'bash scripts/restore-generated-state.sh --exact --ref "${CONTENT_SHA}"'

            def date = sh(returnStdout: true, script: 'date +%Y%m%d').trim()
            env.IMAGE_TAG = "${params.BRANCH}-${date}-${env.CONTENT_SHORT}"
            env.US_IMAGE = "${env.HARBOR_URL}/${env.IMAGE_REPO}:${env.IMAGE_TAG}"
            env.CN_IMAGE = "${env.CN_REGISTRY}/${env.IMAGE_REPO}:${env.IMAGE_TAG}"
            currentBuild.description = "${env.IMAGE_TAG} tooling:${env.TOOLING_SHORT}"
            echo "US Image: ${env.US_IMAGE}"
            echo "CN Image: ${env.CN_IMAGE}"
        }
    }
}
```
