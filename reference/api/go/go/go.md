# Go SDK 参考

<Admonition type="info" title="Note">

在使用 Go SDK 执行操作时，您可以使用以下两种方法进行身份验证：

- 使用 API 密钥

    要获取 API 密钥，请按照[API 密钥](/docs/manage-api-keys)中的说明进行操作。

- 使用集群令牌

    要获取集群令牌，请使用冒号（:）将目标集群的用户名和密码连接起来，如 `username:password`。注意，BYOC 集群仅支持使用集群令牌进行身份验证。

</Admonition>

欢迎使用 Go SDK 参考!
