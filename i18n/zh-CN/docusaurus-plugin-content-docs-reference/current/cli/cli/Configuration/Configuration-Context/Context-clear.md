# clear

此操作会移除当前活动的集群上下文。集群 ID、endpoint、database 和 plan 都会被清除。在切换组织之前，或排查过期上下文状态问题时使用此操作。

## 概要\{#synopsis}

```bash
zilliz context clear
```

## 示例\{#example}

```bash
zilliz context clear
```
